In WordPress

Apply it in the kit

  1. Edit any page with Elementor → hamburger → Site Settings → Global Fonts.
  2. Primary + Secondary family: Source Serif 4. Text stays Inter.
  3. Secondary line-height: 1.2 (it is 1.8em today).
  4. Accent: Inter, uppercase, italic off, tracking 0.14em.
  5. H1 widget → Primary. Section H2s → Secondary. Nav/buttons stay Inter.
  6. Elementor → Settings → Advanced → Google Fonts Load = Swap. Stop loading Playfair.
  7. Update the kit, then purge LiteSpeed. Full click path: ELEMENTOR-SITE-SETTINGS.md.
