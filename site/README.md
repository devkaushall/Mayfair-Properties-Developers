# HTML preview site

Canonical front-end for Elementor rebuild. Locked kit only.

```bash
python3 -m http.server 8080 --bind 0.0.0.0
```

Start at `index.html` (same as `homepage.html`). Header/footer are Heritage Concierge clones for preview — live WP keeps Theme Builder templates.

`img/villa.webp`, `apt.webp`, `comm.webp` are showroom stills — do not use on Home.
